# Cipher Bot – Loader

## Overview
The **Cipher Project** is a collection of scripts and utilities designed to simplify the loading, management, and execution of macros inside the game.

The project provides a centralized loader system, global functions, and shortcuts that improve organization and usability.

---

## Installation

### PC / Mobile – Main Loader

This method works for both PC and Mobile.

Add the **Main Loader** to one of the following locations:
- Ingame Scripts Editor
- Ingame Macro Editor
- Hotkeys
- Any location where you normally execute macros

🔗 Main Loader  
https://github.com/mrlthebest/Cipher-Scripts/blob/main/loader.lua

---

### PC – Brute Loader

Use this method if you are running the bot directly on PC and do not want to use the Main Loader.

🔗 Brute Loader  
https://github.com/mrlthebest/Cipher-Scripts/blob/main/_cipherLoader.lua

**Steps:**
1. Create a folder inside the bot directory
2. Place the `_cipherLoader.lua` file inside that folder
3. Reload or restart the bot, if necessary
