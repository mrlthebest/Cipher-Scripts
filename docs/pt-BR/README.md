# Cipher Bot – Loader

## Visão Geral
O **Cipher Project** é um conjunto de scripts e utilitários desenvolvido para simplificar o carregamento, gerenciamento e execução de macros dentro do jogo.

O projeto fornece um sistema centralizado de loader, funções globais e atalhos que melhoram a organização e a usabilidade.

---

## Instalação


### PC / Mobile – Main Loader

Este método funciona tanto para PC quanto para Mobile.

Adicione o **Main Loader** em um dos seguintes locais:
- Ingame Scripts Editor
- Ingame Macro Editor
- Hotkeys
- Qualquer local onde você normalmente executa macros

🔗 Main Loader  
https://github.com/mrlthebest/Cipher-Scripts/blob/main/loader.lua

---

### PC – Brute Loader

Utilize este método se você estiver executando o bot diretamente no PC e não quiser utilizar o Main Loader.

🔗 Brute Loader  
https://github.com/mrlthebest/Cipher-Scripts/blob/main/_cipherLoader.lua

**Passos:**
1. Crie uma pasta dentro do diretório do bot
2. Coloque o arquivo `_cipherLoader.lua` dentro dessa pasta
3. Recarregue ou reinicie o bot, se necessário
